AVIONIX GLOW

Configure an addressable-LED light-painting rig on an RP2040-Zero — strips, triggers, drawing speed, source images — and generate the Arduino sketch.

target: Waveshare RP2040-Zero
lib: Adafruit_NeoPixel · Arduino-Pico core
output: single .ino sketch
Setup Saves strips, pins, control mode, speed source and all their settings to a .json file — load it back any time instead of re-entering everything. Images and patterns aren't included; re-add those after loading.

Image control

How the rig advances between images and toggles drawing on/off.

Drawing speed

How fast the rig steps through the image's columns. Physical light-painting speed should track how fast the rig itself moves through space.

LED strips

One entry per physical strip driven from its own GPIO. All strips play back the same image, each resampled to its own pixel count.

Images

Each image is resampled to — columns wide by each strip's LED count tall, one vertical strip-column per step of the draw.

Every image is resampled to this many columns so the sketch can index them uniformly. Higher = smoother image, more flash.

Live preview

Simulates what the physical rig shows: the strip on the left stays put and renders its current column live; time flows to the right as an infinite scrolling ribbon, newest column always appearing right next to the strip while everything already drawn scrolls away — the way a long exposure builds up as the strip travels past. Patterns never repeat a fixed frame; uploaded images loop. Each LED is a 2×2-pixel block, upscaled for visibility.

Before you flash

    AVIONIX GLOW runs entirely in this page — images are resampled in your browser and nothing is uploaded anywhere. Pin numbers are GPIO numbers (GPxx); cross-check them against your RP2040-Zero's silkscreen, since a couple of pins are reserved for the onboard NeoPixel / flash on some board revisions.
