Map Telemetry Log Columns
Which column represents elapsed time - used to drive playback speed. Values should be in seconds (or a consistent unit; the Speed control can compensate for milliseconds, etc.) and increase through the log.
Map each column you want to play back to the instrument data source it represents. Columns left as "Ignore" are skipped entirely.
Export Video
Renders the entire loaded log through the instrument cluster and encodes it directly - not a real-time screen recording, so a long log doesn't take real time to export. The whole thing is done in your browser; nothing is uploaded anywhere. Video export needs the WebCodecs API, which this browser doesn't support - try a recent Chrome or Edge.
